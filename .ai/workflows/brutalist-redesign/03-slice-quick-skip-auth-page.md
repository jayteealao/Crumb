# Compressed Slice: quick

Generated by `/wf-quick quick` on 2026-05-17 against slug `brutalist-redesign`. ## 1. Brief (replaces intake)

Add a **debug-build-only "Skip Auth" button** on `LoginScreen` that bypasses Twitter/Reddit OAuth and navigates directly to `HomeScreen`. The motivation is workflow-driven: `runtime-evidence-deferrals[3]` (AC-K6: HomeScreen paper background pixel-check) is currently blocked because OAuth credentials are not provisioned in the verify environment. Without a way past LoginScreen, every downstream slice that needs HomeScreen evidence (tokens AC-K6, components/layouts/screens slices, behaviors data-injector validation) inherits the same block.

*The user explicitly chose this routing (sync + quick in slug-mode) over `hotfix` after the dispatcher flagged that hotfix was the wrong contract for a feature addition.*

**Acceptance criteria (≤3, each objectively verifiable):**

- AC-Q1 — A "Skip Auth (Debug)" button is visible on `LoginScreen` in **debug builds** and **absent** in release builds. Verifiable by `assembleDebug` + visual inspection on emulator, and by `assembleRelease` + decompiling the APK / inspecting the rendered LoginScreen for the absence of the string.
- AC-Q2 — Tapping the button navigates to `HomeScreen.screenRoute(false)` and pops `LoginScreen` from the back stack (back button does not return to login). Verifiable by emulator interaction + `adb shell dumpsys activity activities` to confirm the back stack contains only `HomeScreen`.
- AC-Q3 — `HomeScreen` renders without crashing when reached without a valid access token. The fetch will return empty/unauthenticated, but the screen chrome (top bar, paper background, empty-state messaging) must render correctly. Verifiable by emulator screenshot showing HomeScreen UI present.

## 2. Shape (replaces shape)

- **In scope:**
  - Enable `buildConfig = true` in `app/build.gradle.buildFeatures` so `BuildConfig.DEBUG` is accessible to app-module Kotlin code.
  - Add a `CrumbsButton` to `LoginScreen.kt` Initial-state branch, gated by `if (BuildConfig.DEBUG)`, labelled "Skip Auth (Debug)", styled as a tertiary affordance (visually subordinate to "Connect with X" and "Connect with Reddit").
- **Out of scope:**
  - Any mock-data injection. HomeScreen will be reached with zero bookmarks; the empty state is acceptable evidence for AC-K6.
  - Mock OAuth state. We are not setting `isAccessTokenAvailable` to true — the access flow is bypassed entirely via direct navigation.
  - Replacing the existing OAuth flow. The "Connect with X" / "Connect with Reddit" buttons remain unchanged.
  - Persistent debug-mode state (e.g., "always skip on next launch"). The button is a per-session choice.
- **Known unknowns:**
  - Whether `HomeScreen` is robust enough to render without a token. The viewmodel collect chain may NPE on unauthenticated calls — needs verification on emulator in step 3. If it crashes, the slice escalates and we add a `null`-tolerant empty-state guard.

   - Verification: `./gradlew assembleDebug` succeeds; `app/build/generated/source/buildConfig/debug/.../BuildConfig.java` exists and contains `public static final boolean DEBUG = true;`.

2. **`app/src/main/java/com/github/jayteealao/crumbs/screens/LoginScreen.kt`** — Add `import com.github.jayteealao.crumbs.BuildConfig` at the top of the file (alongside existing `R` and `Screens` imports). Inside the `else ->` branch of the existing `when` block (the "Initial state - prompt to login" arm, line 181-199), append after the existing two `CrumbsButton` calls:
   ```kotlin
   if (BuildConfig.DEBUG) {
       Spacer(modifier = Modifier.height(spacing.md))
       CrumbsButton(
           onClick = {
               navController.navigate(Screens.HOMESCREEN.screenRoute(false)) {
                   popUpTo(Screens.LOGINSCREEN.name) { inclusive = true }
               }
           },
           text = "Skip Auth (Debug)",
           modifier = Modifier.fillMaxWidth()
       )
   }
   ```

4. **Navigation smoke** — Tap "Skip Auth (Debug)". Confirm navigation to HomeScreen. Press back; confirm app exits (LoginScreen was popped, no other entries in back stack).
